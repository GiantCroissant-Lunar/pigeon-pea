# Console App Samples

This directory contains sample projects and experiments for the Dungeon console application.

## Layout

- `src/`
  - C# sample applications that can be built and run like normal projects.
- `tests/`
  - Supporting test and experiment code (C#, Python, and assets) used to validate console/terminal capabilities.

## Kitty Graphics Samples

- `src/KittyDirectTest/`
  - `KittyDirectTest.csproj` and `Program.cs`.
  - Minimal .NET console sample that writes Kitty graphics escape sequences directly to the terminal.

- `tests/kitty/`
  - C# programs for low-level Kitty/iTerm2 behavior experiments.
  - Python scripts for exercising Kitty and iTerm2 image output.
  - Assets generated by `scripts/create_test_image.py` under `assets/`.

These samples are intentionally kept separate from the core console application so they can be used as focused, runnable experiments when debugging or extending terminal rendering support.
