## Executive Summary

This document details using **map container formats** (primarily MBTiles) to package Fantasy Map Generator (FMG) worlds as portable, distributable files compatible with standard mapping tools like mapscii, QGIS, and custom renderers.

**Key Benefits**:

- ✅ Single-file distribution (50-500MB per world)
- ✅ Standard format compatibility (works with mapscii, QGIS, web viewers)
- ✅ Offline support (no internet required)
- ✅ Modding ecosystem (players create and share maps)
- ✅ Mix FMG and OSM data in one container

## Container Format Options

### 1. MBTiles (Recommended)

**What it is**: SQLite database containing map tiles

**Specification**: https://github.com/mapbox/mbtiles-spec

**Structure**:

```sql
-- Metadata table
CREATE TABLE metadata (
    name TEXT,
    value TEXT
);

-- Tiles table
CREATE TABLE tiles (
    zoom_level INTEGER,
    tile_column INTEGER,
    tile_row INTEGER,
    tile_data BLOB
);

-- Indices for fast tile lookup
CREATE UNIQUE INDEX tile_index ON tiles (
    zoom_level, tile_column, tile_row
);
```

**Metadata Fields**:

```json
{
  "name": "Fantasy Europe",
  "type": "baselayer",
  "version": "1.0.0",
  "description": "Procedurally generated fantasy map based on European terrain",
  "attribution": "Generated by PigeonPea FMG",
  "format": "pbf", // or "png", "jpg", "webp"
  "bounds": "-180,-85,180,85",
  "center": "0,0,4",
  "minzoom": "0",
  "maxzoom": "14",
  "json": "{...}" // Optional style JSON
}
```

**Pros**:

- ✅ Industry standard (Mapbox, OSM tools)
- ✅ Single file, easy to distribute
- ✅ Fast random access (SQLite B-tree)
- ✅ Works with mapscii out-of-the-box
- ✅ Extensive tool support

**Cons**:

- ⚠️ SQLite overhead (~10% size increase)
- ⚠️ Not cloud-optimized (needs full file download)

**File Size Examples**:

- Zoom 0-8: ~5-20 MB (world overview)
- Zoom 0-12: ~50-200 MB (continent detail)
- Zoom 0-14: ~500-2000 MB (city-level detail)

### 2. PMTiles

**What it is**: Cloud-optimized single-file format, no SQLite

**Specification**: https://github.com/protomaps/PMTiles

**Structure**:

```
Header (127 bytes)
├── Magic number
├── Version
├── Root directory offset
└── Metadata

Root Directory
├── Tile offset table
└── Tile length table

Metadata (JSON)

Tiles (concatenated)
```

**Pros**:

- ✅ HTTP range request support (partial downloads)
- ✅ No SQLite dependency
- ✅ Faster initial load
- ✅ Smaller file size (~5-10% smaller)

**Cons**:

- ⚠️ Newer format (less tool support)
- ⚠️ mapscii doesn't support it yet

**Best for**: Cloud-hosted maps with streaming

### 3. GeoPackage

**What it is**: OGC standard for geospatial data, SQLite-based

**Specification**: https://www.geopackage.org/

**Pros**:

- ✅ OGC standard (QGIS, ArcGIS support)
- ✅ Supports vector features + tiles
- ✅ More metadata capabilities

**Cons**:

- ⚠️ mapscii doesn't support it
- ⚠️ More complex than MBTiles

**Best for**: GIS tool integration, complex datasets

## Tile Types: Vector vs Raster

### Vector Tiles (Recommended for FMG)

**Format**: Protocol Buffers (`.pbf`)

**Structure**:

```protobuf
message Tile {
    repeated Layer layers = 3;
}

message Layer {
    required string name = 1;
    repeated Feature features = 2;
    repeated Value values = 4;
}

message Feature {
    optional uint64 id = 1;
    repeated uint32 tags = 2;      // Key-value pairs
    optional GeomType type = 3;
    repeated sint32 geometry = 4;  // Command-encoded
}
```

**Tile Layers for FMG**:

```
Layer: water
  - Ocean polygons (from cells where IsOcean)
  - Lake polygons (from FMG Lakes)

Layer: land
  - Land polygons (from cells where IsLand)
  - Biome polygons (grouped by biome type)

Layer: terrain
  - Elevation contours (from heightmap)
  - Mountain polygons (height > threshold)

Layer: rivers
  - River lines (from FMG Rivers)
  - Attributes: width, name, flux

Layer: borders
  - State borders (from FMG States)
  - Culture borders (from FMG Cultures)
  - Province borders (from FMG Provinces)

Layer: roads
  - Road lines (from FMG Routes)
  - Types: main road, sea route

Layer: cities
  - City points (from FMG Burgs)
  - Attributes: name, population, type (capital/city/town)

Layer: markers
  - POI points (from FMG Markers)
  - Types: dungeon, ruin, volcano, sacred site
```

**Coordinate Encoding**:

```
Tile coordinate system: 0-4095 (12-bit)
World coordinates → Tile coordinates

(worldX, worldY) → (tileX, tileY)
tileX = ((worldX - tileBounds.minX) / tileBounds.width) * 4096
tileY = ((worldY - tileBounds.minY) / tileBounds.height) * 4096
```

**Geometry Encoding** (Command-based):

```
Commands:
1 = MoveTo
2 = LineTo
7 = ClosePath

Example river:
[9, 100, 200, 18, 50, 50, 50, 0, 0, 50]
│   │    │    │   │   │   │   │  │  │
│   └────┴────┘   └───┴───┴───┴──┴──┴─ Parameters
│   MoveTo(50,100) LineTo(75,125), LineTo(75,150), LineTo(100,175)
└─ Command (9 = MoveTo with count=1)
```

**Pros**:

- ✅ Small file size (10x smaller than raster)
- ✅ Client-side styling (change colors without regenerating)
- ✅ Smooth zooming (no pixelation)
- ✅ Interactive (click features for info)
- ✅ **This is what mapscii expects!**

**Cons**:

- ⚠️ More complex to generate
- ⚠️ Requires Protobuf encoding

### Raster Tiles (Alternative)

**Format**: PNG, JPEG, WebP

**Structure**: 256x256 pixel images at each zoom level

**Pros**:

- ✅ Simpler to generate (just render to image)
- ✅ Exact visual control
- ✅ Works with any image viewer

**Cons**:

- ❌ Large file size (100x larger than vector)
- ❌ Pixelation when zooming
- ❌ Cannot restyle without regenerating
- ❌ mapscii prefers vector tiles

**Best for**: Pre-rendered artistic maps, thumbnails

## FMG to MBTiles Export Pipeline

### Architecture

```
┌──────────────────────────────────────────────────────────┐
│ 1. FMG Generation                                        │
│    MapData (in-memory)                                   │
└────────────────┬─────────────────────────────────────────┘
                 │
                 ▼
┌──────────────────────────────────────────────────────────┐
│ 2. Tile Generator                                        │
│    For each zoom level (0-14):                          │
│      For each tile (x, y):                              │
│        Extract features in tile bounds                   │
│        Convert to vector tile format                     │
└────────────────┬─────────────────────────────────────────┘
                 │
                 ▼
┌──────────────────────────────────────────────────────────┐
│ 3. Vector Tile Encoder                                  │
│    Encode features as Protobuf (.pbf)                   │
│    Apply coordinate transformation                       │
│    Optimize geometry (simplification)                    │
└────────────────┬─────────────────────────────────────────┘
                 │
                 ▼
┌──────────────────────────────────────────────────────────┐
│ 4. MBTiles Writer                                       │
│    Create SQLite database                               │
│    Insert metadata                                       │
│    Insert tiles (z, x, y, blob)                        │
│    Create indices                                        │
└────────────────┬─────────────────────────────────────────┘
                 │
                 ▼
         fantasy_world.mbtiles
```

### Implementation

```csharp
using System.Data.SQLite;
using NetTopologySuite.Geometries;
using VectorTileSharp;

namespace PigeonPea.Map.Export;

public class MBTilesExporter
{
    private readonly MapData _map;
    private readonly MBTilesOptions _options;

    public MBTilesExporter(MapData map, MBTilesOptions options)
    {
        _map = map;
        _options = options;
    }

    public async Task ExportAsync(string outputPath)
    {
        using var db = CreateDatabase(outputPath);

        // Write metadata
        await WriteMetadataAsync(db);

        // Generate tiles for each zoom level
        for (int z = _options.MinZoom; z <= _options.MaxZoom; z++)
        {
            await GenerateZoomLevelAsync(db, z);
        }

        // Create indices for fast lookup
        await CreateIndicesAsync(db);

        // Optimize database
        await db.ExecuteAsync("VACUUM");
        await db.ExecuteAsync("ANALYZE");
    }

    private SQLiteConnection CreateDatabase(string path)
    {
        var connString = $"Data Source={path};Version=3;";
        var conn = new SQLiteConnection(connString);
        conn.Open();

        // Create tables
        conn.Execute(@"
            CREATE TABLE metadata (name TEXT, value TEXT);
            CREATE TABLE tiles (
                zoom_level INTEGER,
                tile_column INTEGER,
                tile_row INTEGER,
                tile_data BLOB
            );
        ");

        return conn;
    }

    private async Task WriteMetadataAsync(SQLiteConnection db)
    {
        var metadata = new Dictionary<string, string>
        {
            ["name"] = _options.Name ?? "Fantasy Map",
            ["type"] = "baselayer",
            ["version"] = "1.0.0",
            ["description"] = _options.Description ?? "Generated by PigeonPea FMG",
            ["attribution"] = _options.Attribution ?? "© PigeonPea",
            ["format"] = "pbf",
            ["bounds"] = $"0,0,{_map.Width},{_map.Height}",
            ["center"] = $"{_map.Width/2},{_map.Height/2},{_options.DefaultZoom}",
            ["minzoom"] = _options.MinZoom.ToString(),
            ["maxzoom"] = _options.MaxZoom.ToString()
        };

        foreach (var (key, value) in metadata)
        {
            await db.ExecuteAsync(
                "INSERT INTO metadata (name, value) VALUES (@name, @value)",
                new { name = key, value }
            );
        }
    }

    private async Task GenerateZoomLevelAsync(SQLiteConnection db, int zoom)
    {
        var tileCount = CalculateTileCount(zoom);
        Console.WriteLine($"Generating zoom level {zoom} ({tileCount.tiles} tiles)...");

        for (int x = 0; x < tileCount.cols; x++)
        {
            for (int y = 0; y < tileCount.rows; y++)
            {
                var tile = await GenerateTileAsync(zoom, x, y);

                if (tile.Length > 0) // Only save non-empty tiles
                {
                    await db.ExecuteAsync(@"
                        INSERT INTO tiles (zoom_level, tile_column, tile_row, tile_data)
                        VALUES (@z, @x, @y, @data)",
                        new { z = zoom, x, y, data = tile }
                    );
                }
            }
        }
    }

    private async Task<byte[]> GenerateTileAsync(int z, int x, int y)
    {
        // Calculate world bounds for this tile
        var bounds = TileToWorldBounds(x, y, z);

        // Create vector tile
        var tile = new VectorTile();

        // Add layers
        AddWaterLayer(tile, bounds);
        AddLandLayer(tile, bounds);
        AddRiversLayer(tile, bounds);
        AddBordersLayer(tile, bounds);
        AddCitiesLayer(tile, bounds);
        AddMarkersLayer(tile, bounds);

        // Encode to Protobuf
        return tile.Encode();
    }

    private void AddWaterLayer(VectorTile tile, Bounds bounds)
    {
        var layer = tile.AddLayer("water");

        // Add ocean polygons
        foreach (var cell in _map.Cells.Where(c => c.IsOcean && bounds.Contains(c.Center)))
        {
            var polygon = CellToPolygon(cell);
            layer.AddFeature(new VectorTileFeature
            {
                Geometry = polygon,
                Type = GeomType.Polygon,
                Tags = new Dictionary<string, object>
                {
                    ["class"] = "ocean",
                    ["height"] = cell.Height
                }
            });
        }

        // Add lakes
        foreach (var lake in _map.Lakes.Where(l => bounds.Intersects(l)))
        {
            layer.AddFeature(new VectorTileFeature
            {
                Geometry = LakeToPolygon(lake),
                Type = GeomType.Polygon,
                Tags = new Dictionary<string, object>
                {
                    ["class"] = "lake",
                    ["name"] = lake.Name
                }
            });
        }
    }

    private void AddRiversLayer(VectorTile tile, Bounds bounds)
    {
        var layer = tile.AddLayer("rivers");

        foreach (var river in _map.Rivers.Where(r => bounds.Intersects(r)))
        {
            var lineString = RiverToLineString(river);

            layer.AddFeature(new VectorTileFeature
            {
                Geometry = lineString,
                Type = GeomType.LineString,
                Tags = new Dictionary<string, object>
                {
                    ["class"] = "river",
                    ["name"] = river.Name ?? $"River {river.Id}",
                    ["width"] = river.Width,
                    ["length"] = river.Length,
                    ["flux"] = river.Cells?.Count ?? 0
                }
            });
        }
    }

    private void AddCitiesLayer(VectorTile tile, Bounds bounds)
    {
        var layer = tile.AddLayer("cities");

        foreach (var burg in _map.Burgs.Where(b => bounds.Contains(b.Position)))
        {
            var point = new Point(b.Position.X, b.Position.Y);

            layer.AddFeature(new VectorTileFeature
            {
                Geometry = point,
                Type = GeomType.Point,
                Tags = new Dictionary<string, object>
                {
                    ["class"] = "city",
                    ["name"] = b.Name,
                    ["population"] = b.Population,
                    ["type"] = b.Type,
                    ["capital"] = b.Capital,
                    ["state"] = _map.States.FirstOrDefault(s => s.Id == b.State)?.Name ?? ""
                }
            });
        }
    }

    private Bounds TileToWorldBounds(int x, int y, int zoom)
    {
        var tilesPerSide = 1 << zoom; // 2^zoom
        var tileWidth = _map.Width / (double)tilesPerSide;
        var tileHeight = _map.Height / (double)tilesPerSide;

        return new Bounds(
            x: x * tileWidth,
            y: y * tileHeight,
            width: tileWidth,
            height: tileHeight
        );
    }

    private (int tiles, int cols, int rows) CalculateTileCount(int zoom)
    {
        var tilesPerSide = 1 << zoom;
        return (tilesPerSide * tilesPerSide, tilesPerSide, tilesPerSide);
    }
}

public class MBTilesOptions
{
    public string? Name { get; set; }
    public string? Description { get; set; }
    public string? Attribution { get; set; }
    public int MinZoom { get; set; } = 0;
    public int MaxZoom { get; set; } = 12;
    public int DefaultZoom { get; set; } = 4;
    public bool CompressData { get; set; } = true;
}
```

## Vector Tile Encoding Details

### Coordinate Transformation

Vector tiles use integer coordinates in range 0-4095 (12-bit precision).

```csharp
public class TileCoordinateEncoder
{
    private const int TileExtent = 4096;

    public (int x, int y) Encode(Point worldPos, Bounds tileBounds)
    {
        var relX = (worldPos.X - tileBounds.MinX) / tileBounds.Width;
        var relY = (worldPos.Y - tileBounds.MinY) / tileBounds.Height;

        return (
            x: (int)(relX * TileExtent),
            y: (int)(relY * TileExtent)
        );
    }
}
```

### Geometry Simplification

At lower zoom levels, simplify geometry to reduce file size:

```csharp
public class GeometrySimplifier
{
    public LineString Simplify(LineString line, int zoom)
    {
        // Douglas-Peucker algorithm
        var tolerance = CalculateTolerance(zoom);
        return DouglasPeucker.Simplify(line, tolerance);
    }

    private double CalculateTolerance(int zoom)
    {
        // More tolerance at lower zooms
        return zoom switch
        {
            <= 4 => 10.0,
            <= 8 => 5.0,
            <= 12 => 2.0,
            _ => 0.5
        };
    }
}
```

### Feature Filtering

Don't include all features at all zoom levels:

```csharp
public class FeatureFilter
{
    public bool ShouldInclude(Feature feature, int zoom)
    {
        return (feature.Type, zoom) switch
        {
            // Oceans: all zooms
            ("ocean", _) => true,

            // Major rivers: zoom 4+
            ("river", >= 4) when feature.Width > 5 => true,
            ("river", >= 8) when feature.Width > 2 => true,
            ("river", >= 12) => true,

            // Capitals: zoom 2+
            ("city", >= 2) when feature.Capital => true,

            // Cities: zoom 6+
            ("city", >= 6) when feature.Population > 10000 => true,

            // Towns: zoom 10+
            ("city", >= 10) when feature.Population > 1000 => true,

            // All cities: zoom 12+
            ("city", >= 12) => true,

            // State borders: zoom 4+
            ("border", >= 4) when feature.BorderType == "state" => true,

            // Province borders: zoom 8+
            ("border", >= 8) when feature.BorderType == "province" => true,

            _ => false
        };
    }
}
```

## Hybrid World Export

Combine FMG and OSM data in one MBTiles:

```csharp
public class HybridMBTilesExporter
{
    private readonly HybridWorldConfig _config;

    public async Task ExportAsync(string outputPath)
    {
        using var db = CreateDatabase(outputPath);
        await WriteMetadataAsync(db);

        for (int z = 0; z <= 14; z++)
        {
            Console.WriteLine($"Processing zoom {z}...");

            foreach (var (x, y) in GetTiles(z))
            {
                var bounds = TileToWorldBounds(x, y, z);
                var region = _config.GetRegionAt(bounds.Center);

                byte[] tileData = region.Source switch
                {
                    MapDataSource.FMG => await GenerateFMGTileAsync(region, x, y, z),
                    MapDataSource.OSM => await GenerateOSMTileAsync(region, x, y, z),
                    MapDataSource.Hybrid => await GenerateHybridTileAsync(region, x, y, z),
                    _ => Array.Empty<byte>()
                };

                if (tileData.Length > 0)
                {
                    await InsertTileAsync(db, z, x, y, tileData);
                }
            }
        }
    }

    private async Task<byte[]> GenerateHybridTileAsync(
        WorldRegion region, int x, int y, int zoom)
    {
        // Generate both FMG and OSM tiles
        var fmgTile = await GenerateFMGTileAsync(region, x, y, zoom);
        var osmTile = await GenerateOSMTileAsync(region, x, y, zoom);

        // Merge vector tiles
        return MergeVectorTiles(fmgTile, osmTile, region.BlendConfig);
    }

    private byte[] MergeVectorTiles(byte[] tile1, byte[] tile2, BlendConfig config)
    {
        var vt1 = VectorTile.Decode(tile1);
        var vt2 = VectorTile.Decode(tile2);

        var merged = new VectorTile();

        // Take terrain from FMG
        if (config.TerrainSource == MapDataSource.FMG)
        {
            merged.AddLayer(vt1.GetLayer("water"));
            merged.AddLayer(vt1.GetLayer("land"));
        }
        else
        {
            merged.AddLayer(vt2.GetLayer("natural"));
        }

        // Take cities from OSM
        if (config.CitiesSource == MapDataSource.OSM)
        {
            merged.AddLayer(vt2.GetLayer("place"));
        }
        else
        {
            merged.AddLayer(vt1.GetLayer("cities"));
        }

        // Take roads from OSM, rivers from FMG
        merged.AddLayer(vt1.GetLayer("rivers"));
        merged.AddLayer(vt2.GetLayer("roads"));

        return merged.Encode();
    }
}
```

```csharp
public class MapLoader
{
    public async Task<IMapProvider> LoadMapAsync(string path)
    {
        if (path.EndsWith(".mbtiles"))
        {
            return new MBTilesMapProvider(path);
        }
        else if (path.EndsWith(".pmtiles"))
        {
            return new PMTilesMapProvider(path);
        }
        else if (path.EndsWith(".json"))
        {
            // Load FMG JSON directly
            return new FMGMapProvider(path);
        }

        throw new NotSupportedException($"Unknown map format: {path}");
    }
}

public class MBTilesMapProvider : IMapProvider
{
    private readonly SQLiteConnection _db;

    public MBTilesMapProvider(string path)
    {
        _db = new SQLiteConnection($"Data Source={path};Read Only=True;");
        _db.Open();
    }

    public async Task<byte[]> GetTileAsync(int z, int x, int y)
    {
        return await _db.QueryFirstOrDefaultAsync<byte[]>(@"
            SELECT tile_data
            FROM tiles
            WHERE zoom_level = @z
              AND tile_column = @x
              AND tile_row = @y",
            new { z, x, y }
        );
    }

    public Dictionary<string, string> GetMetadata()
    {
        return _db.Query<(string name, string value)>("SELECT name, value FROM metadata")
            .ToDictionary(x => x.name, x => x.value);
    }
}
```

## Performance Optimization

### Tile Generation

```csharp
public class ParallelTileGenerator
{
    public async Task GenerateAllTilesAsync(MapData map, int maxZoom)
    {
        var tiles = new ConcurrentBag<(int z, int x, int y, byte[] data)>();

        await Parallel.ForEachAsync(
            GetAllTileCoordinates(maxZoom),
            new ParallelOptions { MaxDegreeOfParallelism = Environment.ProcessorCount },
            async (coord, ct) =>
            {
                var tileData = await GenerateTileAsync(map, coord.z, coord.x, coord.y);
                if (tileData.Length > 0)
                {
                    tiles.Add((coord.z, coord.x, coord.y, tileData));
                }
            }
        );

        // Batch insert into database
        await BatchInsertTilesAsync(tiles);
    }
}
```

### Compression

```csharp
public class TileCompressor
{
    public byte[] Compress(byte[] vectorTile)
    {
        using var input = new MemoryStream(vectorTile);
        using var output = new MemoryStream();
        using var gzip = new GZipStream(output, CompressionLevel.Optimal);

        input.CopyTo(gzip);
        gzip.Close();

        return output.ToArray();
    }
}

// Result: ~50-70% size reduction
// Uncompressed: 2048 bytes → Compressed: 600 bytes (typical)
```

### Tile Caching

```csharp
public class TileCache
{
    private readonly LRUCache<(int z, int x, int y), byte[]> _memoryCache;
    private readonly string _diskCachePath;

    public async Task<byte[]> GetTileAsync(int z, int x, int y)
    {
        var key = (z, x, y);

        // Check memory cache
        if (_memoryCache.TryGetValue(key, out var cached))
            return cached;

        // Check disk cache
        var diskPath = GetDiskCachePath(z, x, y);
        if (File.Exists(diskPath))
        {
            var data = await File.ReadAllBytesAsync(diskPath);
            _memoryCache.Add(key, data);
            return data;
        }

        // Generate and cache
        var tile = await GenerateTileAsync(z, x, y);
        _memoryCache.Add(key, tile);
        await File.WriteAllBytesAsync(diskPath, tile);

        return tile;
    }
}
```

### MBTiles Validator

```csharp
public class MBTilesValidator
{
    public ValidationResult Validate(string path)
    {
        var errors = new List<string>();
        var warnings = new List<string>();

        using var db = new SQLiteConnection($"Data Source={path};Read Only=True;");

        // Check required tables
        if (!TableExists(db, "metadata")) errors.Add("Missing metadata table");
        if (!TableExists(db, "tiles")) errors.Add("Missing tiles table");

        // Check required metadata
        var metadata = GetMetadata(db);
        if (!metadata.ContainsKey("name")) warnings.Add("Missing 'name' metadata");
        if (!metadata.ContainsKey("format")) errors.Add("Missing 'format' metadata");

        // Validate tile data
        var sampleTile = db.QueryFirstOrDefault<byte[]>(
            "SELECT tile_data FROM tiles LIMIT 1"
        );

        if (sampleTile != null)
        {
            var format = metadata.GetValueOrDefault("format");
            if (format == "pbf" && !IsValidProtobuf(sampleTile))
            {
                errors.Add("Invalid Protobuf data in tiles");
            }
        }

        return new ValidationResult
        {
            IsValid = errors.Count == 0,
            Errors = errors,
            Warnings = warnings
        };
    }
}
```

```csharp
public class StreamingExporter

    public async Task ExportAsync(
        IAsyncEnumerable<MapChunk> chunks,
        string outputPath)
    {
        using var db = CreateDatabase(outputPath);

        await foreach (var chunk in chunks)
```
