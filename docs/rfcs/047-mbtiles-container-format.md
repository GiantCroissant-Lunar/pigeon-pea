# RFC-047: MBTiles Export and Container Format Support

- **Status:** Draft
- **Author:** Claude Agent
- **Date:** 2025-11-22
- **Supersedes:** N/A
- **Related:** RFC-046 (Unified Map Abstraction), RFC-032 (Multi-Backend Rendering)
- **Depends On:** RFC-046 (requires `IMapProvider`, `IMapData` contracts)

## Summary

Implement **MBTiles export and import** for any `IMapProvider`, enabling:

- Export FMG worlds to portable `.mbtiles` files (50-500MB)
- Import MBTiles as `IMapProvider` (treat container as map source)
- Vector tile encoding (Mapbox format) for flexibility
- Compatibility with mapscii, QGIS, and web viewers
- Modding support (players create and share custom maps)

**Key Benefit**: Any map source (FMG, OSM, hybrid) can be packaged as a single distributable file that works with standard mapping tools.

## Motivation

### Current State

Maps are generated in-memory and cannot be:

- Saved for reuse
- Shared with others
- Used with external tools (mapscii, QGIS)
- Cached for offline use

### Problems

1. **No Persistence** - Generated maps are ephemeral
2. **No Distribution** - Cannot share maps with players
3. **No Modding** - Players cannot create custom maps
4. **No Tool Integration** - Cannot use mapscii, QGIS, web viewers
5. **Regeneration Cost** - Must regenerate same map every time

### Goals

1. **Universal Export** - Export any `IMapProvider` to MBTiles
2. **Import as Provider** - Load MBTiles as `IMapProvider`
3. **Standard Format** - Compatible with industry tools
4. **Vector Tiles** - Flexible, small file size, client-side styling
5. **Modding Ecosystem** - Enable community map creation

## Architecture Overview

### MBTiles Format

MBTiles is a SQLite database containing map tiles:

```sql
-- Metadata table
CREATE TABLE metadata (
    name TEXT,
    value TEXT
);

-- Tiles table
CREATE TABLE tiles (
    zoom_level INTEGER,
    tile_column INTEGER,
    tile_row INTEGER,
    tile_data BLOB
);

-- Index for fast lookup
CREATE UNIQUE INDEX tile_index ON tiles (
    zoom_level, tile_column, tile_row
);
```

**Metadata Fields**:

```json
{
  "name": "Fantasy Europe",
  "type": "baselayer",
  "version": "1.0.0",
  "description": "Procedurally generated fantasy map",
  "attribution": "Generated by PigeonPea FMG",
  "format": "pbf", // Vector tiles (Protobuf)
  "bounds": "0,0,2048,2048",
  "center": "1024,1024,4",
  "minzoom": "0",
  "maxzoom": "12"
}
```

### Implementation Note: BruTile.MbTiles

> [!IMPORTANT]
> **Use BruTile.MbTiles instead of raw SQLite operations**
>
> Instead of implementing MBTiles SQLite operations from scratch, leverage the existing `BruTile.MbTiles` package:
>
> - Already in the ecosystem (Mapsui uses it)
> - Battle-tested tile indexing and IO
> - Provides `ITileSource` abstraction
> - Handles edge cases and optimizations
>
> **What we still implement**:
>
> - Vector tile encoding (IMapFeature → Protobuf)
> - Vector tile decoding (Protobuf → IMapFeature)
> - Adapter: `ITileSource` ↔ `IMapProvider`
>
> **NuGet packages**:
>
> ```xml
> <PackageReference Include="BruTile" Version="6.*" />
> <PackageReference Include="BruTile.MbTiles" Version="6.*" />
> ```

### Data Flow: Export

```
1. FmgMapProvider generates MapData
   ↓
2. MBTilesExporter iterates zoom levels (0-12)
   ↓
3. For each tile (z, x, y):
   a. Calculate tile bounds
   b. Get features from IMapData
   c. Encode as vector tile (Protobuf)
   d. Write via BruTile.MbTiles
   ↓
4. Result: fantasy_world.mbtiles (250MB)
```

### Data Flow: Import

```
1. MBTilesMapProvider opens fantasy_world.mbtiles
   ↓
2. GetMapAsync(bounds, zoom):
   a. Calculate tiles for bounds
   b. Query SQLite for tiles
   c. Decode vector tiles
   d. Convert to IMapData
   ↓
3. Return IMapData (works with all renderers)
```

## Detailed Design

### 1. Vector Tile Encoding

#### Vector Tile Structure

Mapbox Vector Tile format (Protocol Buffers):

```protobuf
message Tile {
    repeated Layer layers = 3;
}

message Layer {
    required string name = 1;
    repeated Feature features = 2;
    repeated Value values = 4;
    optional uint32 extent = 5 [default = 4096];
}

message Feature {
    optional uint64 id = 1;
    repeated uint32 tags = 2;      // Key-value pairs
    optional GeomType type = 3;
    repeated sint32 geometry = 4;   // Command-encoded
}

enum GeomType {
    UNKNOWN = 0;
    POINT = 1;
    LINESTRING = 2;
    POLYGON = 3;
}
```

#### Layer Definitions for FMG

```csharp
public static class VectorTileLayers
{
    public const string Water = "water";
    public const string Land = "land";
    public const string Rivers = "rivers";
    public const string Borders = "borders";
    public const string Cities = "cities";
    public const string Roads = "roads";
    public const string Markers = "markers";
}
```

**Layer "water"**:

- Ocean polygons (from cells where IsOcean)
- Lake polygons (from FMG Lakes)
- Attributes: class (ocean/sea/lake), depth

**Layer "land"**:

- Land polygons (from cells where IsLand)
- Biome polygons (grouped by biome type)
- Attributes: biome, elevation, temperature

**Layer "rivers"**:

- River lines (from FMG Rivers)
- Attributes: name, width, flux

**Layer "borders"**:

- State borders (from FMG States)
- Culture borders (from FMG Cultures)
- Attributes: type (state/culture/province), name

**Layer "cities"**:

- City points (from FMG Burgs)
- Attributes: name, population, type (capital/city/town)

**Layer "roads"**:

- Road lines (from FMG Routes)
- Attributes: type (main/sea)

**Layer "markers"**:

- POI points (from FMG Markers)
- Attributes: type (dungeon/ruin/volcano), name

### 2. MBTilesExporter Implementation

```csharp
namespace PigeonPea.Map.Export;

public class MBTilesExporter
{
    private readonly IMapProvider _provider;
    private readonly MBTilesOptions _options;
    private readonly IVectorTileEncoder _encoder;
    private readonly IProgress<ExportProgress>? _progress;

    public MBTilesExporter(
        IMapProvider provider,
        MBTilesOptions options,
        IVectorTileEncoder encoder,
        IProgress<ExportProgress>? progress = null)
    {
        _provider = provider;
        _options = options;
        _encoder = encoder;
        _progress = progress;
    }

    public async Task ExportAsync(string outputPath, CancellationToken ct = default)
    {
        using var db = CreateDatabase(outputPath);

        // Write metadata
        await WriteMetadataAsync(db);

        // Generate tiles for each zoom level
        var totalTiles = CalculateTotalTiles();
        var processedTiles = 0;

        for (int z = _options.MinZoom; z <= _options.MaxZoom; z++)
        {
            await GenerateZoomLevelAsync(db, z, ct);

            // Report progress
            processedTiles += CalculateTilesForZoom(z);
            _progress?.Report(new ExportProgress(z, _options.MaxZoom, processedTiles, totalTiles));
        }

        // Create indices and optimize
        await CreateIndicesAsync(db);
        await OptimizeDatabaseAsync(db);
    }

    private SQLiteConnection CreateDatabase(string path)
    {
        var connString = $"Data Source={path};Version=3;";
        var conn = new SQLiteConnection(connString);
        conn.Open();

        conn.Execute(@"
            CREATE TABLE metadata (name TEXT, value TEXT);
            CREATE TABLE tiles (
                zoom_level INTEGER,
                tile_column INTEGER,
                tile_row INTEGER,
                tile_data BLOB
            );
        ");

        return conn;
    }

    private async Task WriteMetadataAsync(SQLiteConnection db)
    {
        var metadata = new Dictionary<string, string>
        {
            ["name"] = _options.Name ?? "Generated Map",
            ["type"] = "baselayer",
            ["version"] = "1.0.0",
            ["description"] = _options.Description ?? $"Generated by {_provider.ProviderId}",
            ["attribution"] = _options.Attribution ?? "© PigeonPea",
            ["format"] = "pbf",
            ["bounds"] = FormatBounds(_options.Bounds),
            ["center"] = FormatCenter(_options.Bounds, _options.DefaultZoom),
            ["minzoom"] = _options.MinZoom.ToString(),
            ["maxzoom"] = _options.MaxZoom.ToString()
        };

        foreach (var (key, value) in metadata)
        {
            await db.ExecuteAsync(
                "INSERT INTO metadata (name, value) VALUES (@name, @value)",
                new { name = key, value });
        }
    }

    private async Task GenerateZoomLevelAsync(
        SQLiteConnection db,
        int zoom,
        CancellationToken ct)
    {
        var tiles = CalculateTilesForZoom(zoom, _options.Bounds);

        // Parallel generation for performance
        await Parallel.ForEachAsync(
            tiles,
            new ParallelOptions { MaxDegreeOfParallelism = 4, CancellationToken = ct },
            async (tile, ct2) =>
            {
                var tileData = await GenerateTileAsync(tile.Z, tile.X, tile.Y, ct2);

                if (tileData.Length > 0) // Only save non-empty tiles
                {
                    await db.ExecuteAsync(@"
                        INSERT INTO tiles (zoom_level, tile_column, tile_row, tile_data)
                        VALUES (@z, @x, @y, @data)",
                        new { z = tile.Z, x = tile.X, y = tile.Y, data = tileData });
                }
            });
    }

    private async Task<byte[]> GenerateTileAsync(int z, int x, int y, CancellationToken ct)
    {
        // Calculate world bounds for this tile
        var bounds = TileToBounds(x, y, z);

        // Get map data from provider
        var mapData = await _provider.GetMapAsync(bounds, ct);

        // Get features for this tile
        var features = mapData.GetFeatures(bounds, new ZoomLevel(z));

        // Encode as vector tile
        var vectorTile = _encoder.Encode(features, bounds, z);

        // Compress (gzip)
        return CompressTile(vectorTile);
    }

    private BoundingBox TileToBounds(int x, int y, int zoom)
    {
        var tilesPerSide = 1 << zoom; // 2^zoom
        var tileWidth = _options.Bounds.Width / tilesPerSide;
        var tileHeight = _options.Bounds.Height / tilesPerSide;

        return new BoundingBox(
            _options.Bounds.X + (x * tileWidth),
            _options.Bounds.Y + (y * tileHeight),
            tileWidth,
            tileHeight);
    }

    private byte[] CompressTile(byte[] data)
    {
        using var input = new MemoryStream(data);
        using var output = new MemoryStream();
        using var gzip = new GZipStream(output, CompressionLevel.Optimal);

        input.CopyTo(gzip);
        gzip.Close();

        return output.ToArray();
    }
}

public record MBTilesOptions
{
    public string? Name { get; init; }
    public string? Description { get; init; }
    public string? Attribution { get; init; }
    public BoundingBox Bounds { get; init; } = new(0, 0, 2048, 2048);
    public int MinZoom { get; init; } = 0;
    public int MaxZoom { get; init; } = 12;
    public int DefaultZoom { get; init; } = 4;
}

public record ExportProgress(
    int CurrentZoom,
    int MaxZoom,
    int TilesProcessed,
    int TotalTiles)
{
    public double Percentage => (double)TilesProcessed / TotalTiles * 100;
}
```

### 3. IVectorTileEncoder Interface

```csharp
namespace PigeonPea.Map.Encoding;

public interface IVectorTileEncoder
{
    /// <summary>
    /// Encode features as Mapbox Vector Tile (Protobuf format)
    /// </summary>
    byte[] Encode(
        IEnumerable<IMapFeature> features,
        BoundingBox tileBounds,
        int zoom);
}

public class VectorTileEncoder : IVectorTileEncoder
{
    public byte[] Encode(
        IEnumerable<IMapFeature> features,
        BoundingBox tileBounds,
        int zoom)
    {
        var tile = new VectorTile.Tile();

        // Group features by layer
        var layerGroups = features.GroupBy(GetLayerName);

        foreach (var group in layerGroups)
        {
            var layer = new VectorTile.Tile.Layer
            {
                Name = group.Key,
                Version = 2,
                Extent = 4096
            };

            foreach (var feature in group)
            {
                var vtFeature = EncodeFeature(feature, tileBounds);
                if (vtFeature != null)
                {
                    layer.Features.Add(vtFeature);
                }
            }

            if (layer.Features.Count > 0)
            {
                tile.Layers.Add(layer);
            }
        }

        // Serialize to Protobuf
        using var ms = new MemoryStream();
        ProtoBuf.Serializer.Serialize(ms, tile);
        return ms.ToArray();
    }

    private string GetLayerName(IMapFeature feature) => feature.Kind switch
    {
        FeatureKind.Ocean or FeatureKind.Sea or FeatureKind.Lake => VectorTileLayers.Water,
        FeatureKind.River or FeatureKind.Stream => VectorTileLayers.Rivers,
        FeatureKind.Capital or FeatureKind.City or FeatureKind.Town or FeatureKind.Village => VectorTileLayers.Cities,
        FeatureKind.Road or FeatureKind.Path => VectorTileLayers.Roads,
        FeatureKind.CountryBorder or FeatureKind.StateBorder => VectorTileLayers.Borders,
        FeatureKind.Dungeon or FeatureKind.Marker => VectorTileLayers.Markers,
        _ => VectorTileLayers.Land
    };

    private VectorTile.Tile.Feature? EncodeFeature(
        IMapFeature feature,
        BoundingBox tileBounds)
    {
        var vtFeature = new VectorTile.Tile.Feature
        {
            Id = (ulong)feature.FeatureId.GetHashCode()
        };

        // Encode geometry
        var geometry = EncodeGeometry(feature.Geometry, tileBounds);
        if (geometry == null || geometry.Count == 0)
            return null; // Feature outside tile

        vtFeature.Geometry.AddRange(geometry);
        vtFeature.Type = GetGeometryType(feature.Geometry);

        // Encode properties as tags
        var tags = EncodeProperties(feature);
        vtFeature.Tags.AddRange(tags);

        return vtFeature;
    }

    private List<uint>? EncodeGeometry(IGeometry geometry, BoundingBox tileBounds)
    {
        // Convert world coordinates to tile coordinates (0-4096)
        // Use command encoding: MoveTo(1), LineTo(2), ClosePath(7)

        var commands = new List<uint>();

        if (geometry is Point point)
        {
            var (x, y) = WorldToTile(point.X, point.Y, tileBounds);
            commands.Add(EncodeCommand(CommandType.MoveTo, 1));
            commands.Add(EncodeParameter(x));
            commands.Add(EncodeParameter(y));
        }
        else if (geometry is LineString line)
        {
            var coords = line.Coordinates.Select(c => WorldToTile(c.X, c.Y, tileBounds)).ToList();
            if (coords.Count < 2) return null;

            // MoveTo first point
            commands.Add(EncodeCommand(CommandType.MoveTo, 1));
            commands.Add(EncodeParameter(coords[0].x));
            commands.Add(EncodeParameter(coords[0].y));

            // LineTo remaining points
            commands.Add(EncodeCommand(CommandType.LineTo, coords.Count - 1));
            for (int i = 1; i < coords.Count; i++)
            {
                var dx = coords[i].x - coords[i - 1].x;
                var dy = coords[i].y - coords[i - 1].y;
                commands.Add(EncodeParameter(dx));
                commands.Add(EncodeParameter(dy));
            }
        }
        // ... similar for Polygon

        return commands;
    }

    private (int x, int y) WorldToTile(double worldX, double worldY, BoundingBox tileBounds)
    {
        var relX = (worldX - tileBounds.X) / tileBounds.Width;
        var relY = (worldY - tileBounds.Y) / tileBounds.Height;

        return (
            (int)(relX * 4096),
            (int)(relY * 4096)
        );
    }
}
```

### 4. MBTilesMapProvider Implementation

```csharp
namespace PigeonPea.Plugin.Map.MBTiles;

public class MBTilesMapProvider : IMapProvider, IDisposable
{
    private readonly string _filePath;
    private readonly SQLiteConnection _db;
    private readonly IVectorTileDecoder _decoder;
    private readonly Dictionary<string, string> _metadata;

    public string ProviderId => $"mbtiles:{Path.GetFileName(_filePath)}";

    public MapProviderCapabilities Capabilities =>
        MapProviderCapabilities.FullWorld |
        MapProviderCapabilities.Offline |
        MapProviderCapabilities.Cacheable;

    public MBTilesMapProvider(string filePath, IVectorTileDecoder decoder)
    {
        _filePath = filePath;
        _decoder = decoder;

        _db = new SQLiteConnection($"Data Source={filePath};Read Only=True;");
        _db.Open();

        _metadata = LoadMetadata();
    }

    public async Task<IMapData> GetMapAsync(BoundingBox bounds, CancellationToken ct = default)
    {
        // Determine appropriate zoom level for bounds
        var zoom = CalculateOptimalZoom(bounds);

        // Get tiles that intersect bounds
        var tiles = CalculateTilesForBounds(bounds, zoom);

        // Load tiles from database
        var tileData = new List<VectorTile.Tile>();

        foreach (var (z, x, y) in tiles)
        {
            var data = await LoadTileAsync(z, x, y, ct);
            if (data != null)
            {
                tileData.Add(_decoder.Decode(data));
            }
        }

        // Convert to IMapData
        return new MBTilesMapData(tileData, bounds, zoom);
    }

    public bool CanServe(BoundingBox bounds)
    {
        // Check if bounds intersect MBTiles bounds
        var mbBounds = ParseBounds(_metadata["bounds"]);
        return mbBounds.Intersects(bounds);
    }

    private async Task<byte[]?> LoadTileAsync(int z, int x, int y, CancellationToken ct)
    {
        var data = await _db.QueryFirstOrDefaultAsync<byte[]>(@"
            SELECT tile_data
            FROM tiles
            WHERE zoom_level = @z
              AND tile_column = @x
              AND tile_row = @y",
            new { z, x, y });

        if (data == null) return null;

        // Decompress if needed
        return DecompressTile(data);
    }

    private byte[] DecompressTile(byte[] data)
    {
        using var input = new MemoryStream(data);
        using var output = new MemoryStream();
        using var gzip = new GZipStream(input, CompressionMode.Decompress);

        gzip.CopyTo(output);
        return output.ToArray();
    }

    public void Dispose()
    {
        _db?.Dispose();
    }
}
```
