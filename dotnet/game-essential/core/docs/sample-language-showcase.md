## High Elvish

**Aesthetic**: Flowing, melodic, vowel-rich
**Inspiration**: Tolkien's Quenya and Sindarin
**Word Order**: SVO (Subject-Verb-Object)

### Phonological Characteristics

- **Vowels**: a, e, i, o, u, á, é, í (8 vowels including long forms)
- **Consonants**: l, r, n, m, s, h, t, th, d, v, f (soft, liquid sounds)
- **Diphthongs**: ae, ai, ei
- **Syllable Structure**: Predominantly CV and CVC, with occasional CCV

### Sample Names

```
Personal Names:
- Aelóriel (feminine, "light maiden")
- Thaloren (masculine, "stone guardian")
- Mirathel (feminine, "jewel star")
- Elendil (masculine, "star friend")
- Lothíriel (feminine, "flower maiden")

Place Names:
- Silvanthir (forest realm)
- Minaloth (tower of flowers)
- Thalassë (great sea)

Item Names:
- Mirilómë (jewel of night)
- Silmarien (moonstone)
```

### Sample Phrases

| English | High Elvish | Literal Translation |
|---------|-------------|---------------------|
| Hello | Aelór | Light-greeting |
| Farewell | Namarië | Be well |
| Thank you | Hantale | Gift-thanks |
| Friend | Mellon | Companion |
| Star | Elen | Star |
| Forest | Silva | Forest |
| Water | Nen | Water |
| Light | Lóme | Light |

### Grammar Features

**Pluralization**: Add suffix "-lir"
- Elen → Elenlir (stars)
- Mellon → Mellonlir (friends)

**Genitive (Possession)**: Add suffix "-ien"
- Elen → Elenien (of the star)
- Silva → Silvien (of the forest)

**Feminine Marker**: Add suffix "-iel"
- Aelor → Aelóriel (light maiden)
- Mir → Miriel (jewel maiden)

**Agent Noun**: Add suffix "-ar"
- Thal → Thalar (stone-worker)
- Mir → Mirar (jeweler)

### Example Sentences

```
English: The elf sees the star
High Elvish: Elda cene elen
Structure: [Subject] [Verb] [Object]

English: The forest is beautiful
High Elvish: Silva ná vanya
Structure: [Subject] [Verb] [Adjective]
```

## Dwarvish

**Aesthetic**: Harsh, guttural, consonant-heavy
**Inspiration**: Tolkien's Khuzdul, Hebrew
**Word Order**: VSO (Verb-Subject-Object)

### Phonological Characteristics

- **Vowels**: a, e, i, o, u (5 basic vowels)
- **Consonants**: k, g, kh, gh, r, rr, z, zh, d, t, b, p, m, n (harsh stops and gutturals)
- **Syllable Structure**: Complex - CVC, CCVC, CVCC common
- **Consonant Clusters**: Heavy use of initial and final clusters

### Sample Names

```
Personal Names:
- Khazad (masculine, "dwarf")
- Gimrak (masculine, "axe-bearer")
- Thorgrund (masculine, "thunder-stone")
- Barazûn (masculine, "red-mountain")
- Khazra (feminine, "dwarf-woman")

Clan Names:
- Khazad-dûm (dwarf-halls)
- Baraz-gund (red-stone clan)
- Gundabad (stone-fortress)

Item Names:
- Khazad-dum (dwarf-delving)
- Baraz-khel (red-silver)
- Gund-thrak (stone-hammer)
```

### Sample Phrases

| English | Dwarvish | Literal Translation |
|---------|----------|---------------------|
| Greetings | Khazûn | Stone-greeting |
| Farewell | Baraz-dûm | Red-halls (safe journey) |
| Thank you | Gund-rak | Stone-gift |
| Friend | Khel-zad | Silver-companion |
| Mountain | Baraz | Red-peak |
| Stone | Gund | Stone |
| Gold | Khel | Silver/precious |
| Axe | Gimr | Axe |

### Grammar Features

**Triconsonantal Roots**: Words built from 3-consonant roots
- K-H-Z (dwarf): Khazad, Khazûn, Khazra
- G-N-D (stone): Gund, Gundabad, Gundrak
- B-R-Z (red/fire): Baraz, Barazûn, Barazdûm

**Pluralization**: Add suffix "-ûl"
- Khazad → Khazadûl (dwarves)
- Gund → Gundûl (stones)

**Compound Formation**: Direct concatenation with optional connector
- Khazad + dûm → Khazad-dûm (dwarf-halls)
- Baraz + gund → Baraz-gund (red-stone)

### Example Sentences

```
English: The dwarf forges the axe
Dwarvish: Gimrak khazad gimr
Structure: [Verb] [Subject] [Object]

English: The mountain stands strong
Dwarvish: Gund baraz khazûn
Structure: [Verb] [Subject] [Adjective]
```

## Draconic

**Aesthetic**: Ancient, booming, sibilant
**Inspiration**: Dragon speech from various fantasy settings
**Word Order**: VSO (Verb-Subject-Object)

### Phonological Characteristics

- **Vowels**: a, e, i, o, u, aa, ee (including long vowels)
- **Consonants**: s, z, sh, zh, th, dh, k, g, r, h, x (sibilants and fricatives)
- **Syllable Structure**: Varied - V, CV, CVC, CCVC
- **Special Features**: Emphasis on hissing and resonant sounds

### Sample Names

```
Dragon Names:
- Skaraxes (masculine, "fire-breath")
- Zharothar (masculine, "ancient-flame")
- Xarathos (masculine, "sky-lord")
- Shazira (feminine, "silver-scale")
- Tharaxis (masculine, "thunder-wing")

Ancient Titles:
- Drakaar (dragon-lord)
- Skaroth (fire-ancient)
- Zharakul (flame-eternal)

Artifact Names:
- Xar-thaal (sky-stone)
- Skar-zhul (fire-heart)
- Thar-axis (thunder-power)
```

### Sample Phrases

| English | Draconic | Literal Translation |
|---------|----------|---------------------|
| Greetings | Skaroth | Fire-ancient |
| Farewell | Zharakul | Flame-eternal |
| Power | Axis | Power |
| Fire | Skar | Fire |
| Sky | Xar | Sky |
| Ancient | Thar | Ancient |
| Scale | Zhir | Scale |
| Wing | Thax | Wing |

### Grammar Features

**Compound Words**: Extensive use of compounds
- Skar + axis → Skaraxis (fire-power)
- Xar + thar → Xarthar (sky-ancient)
- Zhir + thax → Zhirthax (scale-wing)

**Intensification**: Doubling vowels for emphasis
- Skar → Skaar (great fire)
- Thar → Thaar (very ancient)

**Verb-First Structure**: Actions precede actors
- Breathes dragon fire → Skar drakaar axis

### Example Sentences

```
English: The dragon breathes fire
Draconic: Skar drakaar axis
Structure: [Verb] [Subject] [Object]

English: The ancient one guards the treasure
Draconic: Zharak tharaxis xarzhul
Structure: [Verb] [Subject] [Object]
```

## Language Comparison

### Phonological Comparison

| Feature | High Elvish | Dwarvish | Draconic |
|---------|-------------|----------|----------|
| Vowel Count | 8 | 5 | 7 |
| Consonant Count | 11 | 14 | 11 |
| Syllable Complexity | Simple | Complex | Varied |
| Consonant Clusters | Rare | Common | Moderate |
| Aesthetic | Flowing | Harsh | Sibilant |

### Grammatical Comparison

| Feature | High Elvish | Dwarvish | Draconic |
|---------|-------------|----------|----------|
| Word Order | SVO | VSO | VSO |
| Morphology | Agglutinative | Root-based | Compound-heavy |
| Pluralization | Suffix (-lir) | Suffix (-ûl) | Prefix (zha-) |
| Compounds | Connector | Direct | Direct |

### Name Length Comparison

Average syllable count in generated names:

- **High Elvish**: 3-4 syllables (flowing, elegant)
- **Dwarvish**: 2-3 syllables (compact, strong)
- **Draconic**: 3-5 syllables (imposing, ancient)

## Usage Examples

### Loading Languages

```csharp
// Load all three languages
await languageService.LoadLanguageAsync("high-elvish", "Examples/high-elvish.json");
await languageService.LoadLanguageAsync("dwarvish", "Examples/dwarvish.json");
await languageService.LoadLanguageAsync("draconic", "Examples/draconic.json");
```

### Generating Names

```csharp
// Generate Elvish names (elegant, flowing)
var elvishNames = languageService.GenerateNames("high-elvish", 5, new NameGenerationOptions
{
    MinSyllables = 3,
    MaxSyllables = 4,
    Type = NameType.Personal
});
// Output: Aelóriel, Thaloren, Mirathel, Elendil, Lothíriel

// Generate Dwarvish names (short, harsh)
var dwarvishNames = languageService.GenerateNames("dwarvish", 5, new NameGenerationOptions
{
    MinSyllables = 2,
    MaxSyllables = 3,
    Type = NameType.Personal
});
// Output: Khazad, Gimrak, Thorgrund, Barazûn, Gundrak

// Generate Draconic names (imposing, ancient)
var draconicNames = languageService.GenerateNames("draconic", 5, new NameGenerationOptions
{
    MinSyllables = 3,
    MaxSyllables = 5,
    Type = NameType.Personal
});
// Output: Skaraxes, Zharothar, Xarathos, Shazira, Tharaxis
```

### Translation Examples

```csharp
// Translate to High Elvish
var elvish = await languageService.TranslateAsync("hello friend", "english", "high-elvish");
// Output: "Aelór mellon"

// Translate to Dwarvish
var dwarvish = await languageService.TranslateAsync("stone mountain", "english", "dwarvish");
// Output: "Gund baraz"

// Translate to Draconic
var draconic = await languageService.TranslateAsync("fire dragon", "english", "draconic");
// Output: "Skar drakaar"
```

## Extending the Languages

### Adding New Words

Add entries to the lexicon files:

```json
{
  "word": "newword",
  "meaning": "new concept",
  "partOfSpeech": "noun",
  "root": "new",
  "etymology": "from 'new' (novel) + 'word' (term)"
}
```

### Creating Dialects

Use sound changes to create regional variants:

```json
{
  "id": "wood-elvish",
  "parentLanguageId": "high-elvish",
  "soundChanges": [
    {"source": "th", "target": "f"},
    {"source": "á", "target": "a"}
  ]
}
```

### Custom Name Lists

Train Markov chains on custom name lists for specific styles.
